# Contributing

Ogni contributo sui dati deve:

1. citare almeno una fonte verificabile;
2. distinguere il testo della norma dalla sua interpretazione;
3. non trasformare una correlazione temporale in causalità;
4. registrare fonti discordanti quando materialmente rilevanti;
5. indicare il periodo a cui si riferisce ogni indicatore;
6. esplicitare la popolazione interessata;
7. evitare giudizi complessivi non derivabili dai dati.

Le pull request che modificano una misura dovrebbero spiegare in modo sintetico quali fonti sono state aggiunte o corrette.
